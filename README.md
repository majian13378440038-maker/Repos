# STM32Project

江协科技 STM32 入门教程（标准库 / Keil MDK）逐节练习代码归档。
按课节顺序分目录存放，每个目录是一个独立的 Keil 工程（`Project.uvprojx`）。

> 编译产物（`Objects/`、`Listings/`、`DebugConfig/`、`*.uvguix.*` 等）已在 `.gitignore` 中排除，仓库只保留源码、工程文件与外设驱动。
